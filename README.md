# Aurelia Stomatologia

Сайт частной стоматологической клиники **Aurelia** (Варшава, ul. Mokotowska 48).

Премиальная многостраничная витрина: услуги, команда, прайс, запись на визит, контакты. Языки: **PL / EN / RU**.

## Страницы

| Путь | Содержание |
|---|---|
| `/` | Главная: клиника, услуги, врачи, отзывы, FAQ |
| `/uslugi` | Полный перечень услуг |
| `/zespol` | Команда врачей |
| `/cennik` | Ориентировочные цены |
| `/wizyta` | Форма записи на приём |
| `/kontakt` | Адрес, часы, карта |
| `/rodo` | Политика конфиденциальности |

Заявки с формы хранятся только в браузере (`localStorage`) — это демо без серверной базы.

## Запуск

Нужны **Node.js 22** и npm.

```bash
npm install
npm run dev
```

Сайт откроется на `http://localhost:8080`.

Сборка:

```bash
npm run build
```

## Стек

- React 19 + TanStack Start / Router
- Tailwind CSS v4
- TypeScript
- Lucide-иконки

## Заметка

Это демо-сайт для презентации клиники: адрес, телефоны и врачи — вымышленные. Перед публикацией подставьте реальные данные, NIP и политику RODO.
