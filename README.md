# MiDental

Сайт частного стоматологического кабинета **MiDental** (Stara Iwiczna, ul. Tukanów 12 lok. U3).

Многостраничная витрина: услуги, кабинет, прайс с реальными ценами, запись на визит, контакты. Языки: **PL / EN / RU**.
